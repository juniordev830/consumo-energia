# Experimentos de tarifas .NET

- F#: dotnet fsi labs/fsharp/EnergyTariff.fsx
- Visual Basic .NET: dotnet run --project labs/vbnet/EnergyCalculator.vbproj

Exemplos usam Decimal, validam consumos e precos nao negativos e arredondam o total a centavos. Nao substituem o calculador C# existente nem representam regulacao tarifaria brasileira.
